## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Tampering | store.py current.json write | mitigate | validate_incidents_file (IncidentsFile.model_validate) gate BEFORE atomic write; on violation, skip write and preserve last-good file (D-15, V5) |
| T-05-03-02 | Tampering | partial/corrupt write on crash | mitigate | atomic_write_json (.tmp + os.replace) — reader never sees a half-written file (reused Phase-1 pattern) |
| T-05-03-03 | Repudiation | missing source attribution | mitigate | IncidentRecord requires non-empty outlet/url/date; schema gate rejects incidents lacking attribution (NEWS-05) |
| T-05-03-04 | Tampering | duplicate/unstable pins across runs | mitigate | Deterministic id = sha256(url)[:16] makes merge idempotent; re-runs do not multiply pins (D-11) |
</threat_model>
