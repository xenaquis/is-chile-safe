## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external RSS feeds -> pipeline | Untrusted third-party content (titles, descriptions, URLs) enters here |
| pipeline -> DeepSeek API | Outbound API call carrying the secret DEEPSEEK_API_KEY |
| DeepSeek response -> ClassifierOutput | Untrusted LLM output (may hallucinate CUT codes, malformed JSON) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-02-01 | Spoofing/Tampering | classifier.py LLM-returned commune_cut | mitigate | Reject if commune_cut not in VALID_CUTS (346 set) and if confidence < 0.6 (D-07); temp 0.0; never invent codes — anti-hallucination central guard |
| T-05-02-02 | Information Disclosure | DEEPSEEK_API_KEY | mitigate | Read from os.environ only (dotenv dev / repo secret CI); never hardcoded, never logged (V2) |
| T-05-02-03 | Denial of Service | feeds.py feed fetch | mitigate | Per-feed try/except returns []; ~10s timeout + tenacity; one down feed never blocks the run (NEWS-01, D-04) |
| T-05-02-04 | Tampering | malformed/truncated DeepSeek JSON | mitigate | json.loads in try/except + empty-content retry + ClassifierOutput.model_validate; return None on any failure (Pitfall 4) |
| T-05-02-SC | Tampering | feedparser/openai pip install | mitigate | Blocking-human legitimacy checkpoint (Task 1) verifies PyPI before install; both CITED in CLAUDE.md |
