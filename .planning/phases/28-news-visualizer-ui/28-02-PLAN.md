## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query string → client `<script>` on both pages | Untrusted, user/attacker-editable input parsed by `parseFilterParams` (Plan 28-01) then used only for DOM attribute comparison, never string interpolation into HTML |
| `#news-facets` JSON node → client `<script>` | Build-time data, LLM-classifier-derived strings inside it (`byFamily[].key`) already escaped at source via `escapeForInlineScript`; this plan adds `anchorDate` to the SAME object, automatically covered |
| Comuna search input (`?q=`, `#news-comuna-q`) → DOM | User-typed/URL-supplied text; assigned to `input.value` only (never innerHTML); matched via `norm()`/`.includes()` against a TRUSTED build-time `data-commune-norm` attribute, never used to construct HTML |

| T-28-05 | Tampering | Reflected `?q=` content in the comuna typeahead | mitigate | `input.value = initialQ` assignment only (T-12-01); match/highlight logic (if any) slices the TRUSTED `data-commune-norm`/`data-name`-equivalent attribute, never injects the raw query string into `innerHTML` |
