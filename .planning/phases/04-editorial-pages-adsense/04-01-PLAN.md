  <action>
    Create the validator copying the hreflang.mjs scaffold (dist/ guard, findIndexFiles, failure counting, process.exit(1) on failures). Implement per D-05/D-06/D-07/D-08:
    - extractVisibleText(html): remove `<script>...</script>` blocks FIRST, then `<style>...</style>` blocks, then strip remaining `<[^>]*>` tags, decode the 4 named entities (&amp; &lt; &gt; &nbsp;), collapse whitespace. Order matters (Pitfall 3) — script/style content must be removed before tag stripping so JS identifiers do not produce false positives.
    - normalizeAccents(str): `str.normalize('NFD').replace(/[̀-ͯ]/g, '')`. Apply to BOTH extracted text AND each term (Pitfall 2).
    - buildTermPattern: use negative lookbehind/lookahead boundaries `(?<![a-z0-9])TERM(?![a-z0-9])` — NOT `\b` (D-08; `\b` breaks on accented text per Pattern 5). Escape regex specials in the term.
    - FORBIDDEN_TERMS list (D-06, extensible array) covering both EN and ES from the UI-SPEC term table: 'zona peligrosa','area peligrosa','comuna peligrosa','barrio peligroso','ranking definitivo','zona segura garantizada','100% seguro','seguridad garantizada','la mas segura', and EN: 'dangerous zone','dangerous area','dangerous commune','dangerous neighborhood','definitive ranking','guaranteed safe','100% safe','guaranteed safety','the safest'. (Terms are accent-stripped/lowercased at match time, so 'la mas segura' matches 'la más segura'.)
    - ALLOW_LIST regexes for the qualifying-phrase exception (D-06, Pitfall 1): check a context window (~100 chars) after each match; if it matches `/en este per[io]+do seg[u]+n datos cead/i` or `/according to cead data for \d{4}/i`, skip the failure. This lets "la más segura en este período según datos CEAD" and "the safest ... according to CEAD data for 2024" pass while bare superlatives fail.
    - On failure: write to stderr in the format `[forbidden-language] FAIL: {page-label}\n  Term: "{term}"\n  Context: "...{excerpt}..."`, count total failures, and `process.exit(1)` if any. On success: `console.log('forbidden-language: PASS ...')`.
    Do NOT inline any forbidden term inside an HTML/text context that the validator would later scan — keep terms only in the FORBIDDEN_TERMS array (a JS array literal is a `<script>`-free .mjs file, never in dist/, so it is safe).
  </action>
