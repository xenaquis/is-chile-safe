## New UI Components — Phase 18

### 1. Choropleth Mode Toggle

**Placement:** Inside `.map-topbar`, to the left of or replacing the existing family select chip (`.chip.select`). On mobile, fits within the horizontally-scrollable `.filters-row`.

**Appearance:** Two `.chip` buttons in a button group:
- "Index" (composite mode, **default active**)
- "By crime" (per-family rate mode)

**Active state:** `.chip.active` — `background: var(--primary); color: #ffffff`
**Inactive state:** `.chip:not(.active)` — `background: var(--card); color: var(--ink); border: 1px solid var(--line)`

**Height:** 44px (touch target requirement).

**Labels:**
- EN: "Index" / "By crime"
- ES: "Índice" / "Por delito"

**Interaction:** Click toggles map choropleth and updates legend title. No animation beyond the existing `transition: background 0.15s` on `.chip`.

**Default state:** Index mode is active on page load (D-05).

---

### 2. Composite Index Stat Card (ResultPanel)

**Placement:** Insert as a new `.panel-section` immediately after `.panel-badge-row` (the level chip row) and before the existing `.stat-card` (homicide rate card). This positions the composite score as the lead metric.

**Structure:**

```
.panel-section.composite-index-section
  h4                       "Crime burden index" / "Índice de carga delictiva"
  .stat-card
    .stat-big              Integer 0–100  (e.g. "42")
    .stat-unit             Band label     (e.g. "Moderate" / "Moderado")
    .ci-rank               "#138 of 346 communes" / "#138 de 346 comunas"
```

**Typography:**
- Score: `.stat-big` — 28px/700 (`--text-display`/`--weight-strong`)
- Band label: `.stat-unit` — 14px/700 (`--text-label`/`--weight-strong`), `color: var(--muted)`
- Rank: `.ci-rank` — 14px/400 (`--text-label`/`--weight-body`), `color: var(--muted)`

**Display precision:** `Math.round(ci.score)` — always integer, never `.toFixed()`.

**Fallback:** When `composite_index` is absent from commune data (pre-2018 communes or data gap), this entire section is omitted. No "N/A" placeholder.

---

### 3. Mandatory Caveat Block

**Placement:** Below the composite index stat card within `.panel-section.composite-index-section`. Also rendered in commune Astro pages below the index score section.

**Always-visible rule:** Never inside a `<details>`, accordion, or collapsed state. D-07 locks this — editorial-risk posture requires unconditional visibility.

**Appearance:**
- Background: `var(--card)` with `border: 1px solid var(--line)`, `border-radius: 8px`
- Left border accent: `border-left: 3px solid var(--primary)` — signals informational, not warning
- Padding: `var(--sm) var(--md)` (8px 16px)
- Font: 14px/400 (`--text-label`/`--weight-body`), `color: var(--muted)`

**CSS class:** `.ci-caveat`

**Bilingual copy (exact, locked by D-07):**

EN:
> Composite of reported crimes (CEAD/SPD), adjusted for SII economic activity. Does not reflect unreported crime. Reference year: 2024.

ES:
> Compuesto de delitos reportados al sistema policial (CEAD/SPD), ajustado por actividad económica SII. No refleja delitos no denunciados. Datos de referencia: 2024.

**Application surfaces:** ResultPanel popup, EN commune page (`/commune/[slug]/`), ES commune page (`/es/comuna/[slug]/`).

---

### 4. Legend Update (Index Mode)

**When in composite index mode,** the existing `.legend` overlay updates:
- **Title:** "Crime Index" (EN) / "Índice Delictivo" (ES) — replaces the current family-specific legend title
- **Swatches:** Same 5-color scale (`--s1` through `--s5`)
- **Labels:** Very Low → Very High (EN) / Muy Bajo → Muy Alto (ES) using `.legend-qual-label`

Existing `.legend-bands` and `.legend-band-row` CSS classes are reused unchanged.

---

### 5. Commune Page Index Section (Astro templates)

**Placement:** Below the existing "Incidence Rate" stat block and above the family breakdown bars.

**Structure (pre-rendered HTML):**

```
<section class="panel-section composite-index-section">
  <h4>Crime burden index / Índice de carga delictiva</h4>
  <div class="stat-card">
    <div class="stat-big">{score}</div>
    <div class="stat-unit">{band_label}</div>
    <div class="ci-rank">#{national_rank} of 346 / #{regional_rank} in region</div>
  </div>
  <div class="ci-caveat">
    {caveat_text}
  </div>
</section>
```

**Rank display format:**
- EN: `#138 of 346 nationally · #12 in Región Metropolitana`
- ES: `#138 de 346 a nivel nacional · #12 en Región Metropolitana`

- Never: "safest", "most dangerous", "la más segura", "el más seguro", "más peligrosa", "más peligroso" without the qualifier "reported / reportado".
- Never: absolute percentage claims ("X% safer than").

**Primary CTA (ResultPanel):** "View {commune} full profile" / "Ver perfil completo de {commune}" — existing `panel-cta` button, unchanged.
