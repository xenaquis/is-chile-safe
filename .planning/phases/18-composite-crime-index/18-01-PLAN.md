## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CEAD/SPD/SII snapshot files -> pipeline | Static data files treated as semi-trusted; a compromised or corrupted feed could inject extreme outlier rates |
| pipeline compute -> static JSON output | Score precision and join correctness must not imply false accuracy |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Tampering | normalize_metric (outlier rate injection from compromised CEAD/SPD feed) | mitigate | winsorize(limits=[0.01,0.01]) clips top/bottom 1% before min-max; test_composite_distribution asserts spread (25th pctile > 10% of max) — a single injected outlier cannot collapse the scale |
| T-18-02 | Tampering | get_exposure_denominator (SII join error inflating denominator) | mitigate | SII_CAP_RATIO=5.0 fallback to INE; test_sii_cap_logic pins Providencia->INE, Las Condes->SII; null-vs-zero guard (dict.get returns None for absence) |
| T-18-03 | Spoofing (editorial false precision) | composite_index score stored as float | mitigate | Score consumed as integer downstream (Math.round); pydantic/test_output_schema asserts score roundable 0-100 and level 1-5 — no false-precision float surfaces |
| T-18-04 | Integrity | year misalignment (using non-2024 source silently) | mitigate | assert_year_alignment fails loudly before any compute; test_year_alignment guards REFERENCE_YEAR==2024 across all three sources |
| T-18-SC | Tampering | pip install scipy | mitigate | scipy approved in RESEARCH Package Legitimacy Audit (PyPI, ~24yr, ~40M/wk, github.com/scipy/scipy, slopcheck OK) — not [ASSUMED]/[SUS]; no blocking checkpoint required |
