KINSHIP maps each ES concept to its accepted EN renderings, for example:
- yerno → son-in-law; suegro/a → father-in-law / mother-in-law / in-law;
- abuelo/a → grandfather / grandmother / grandparent; nieto/a → grandson / granddaughter / grandchild;
- padre → father / dad; madre → mother / mom;
- hijo/a → son / daughter / child;
- hermano/a → brother / sister / sibling;
- tío/a → uncle / aunt; primo/a → cousin; sobrino/a → nephew / niece;
- esposo/a → husband / wife / spouse; cuñado/a → brother-in-law / sister-in-law; nuera → daughter-in-law;
- hijastro/a → stepson / stepdaughter / stepchild; padrastro → stepfather; madrastra → stepmother;
- pareja / expareja / conviviente / pololo/a → partner / ex-partner / boyfriend / girlfriend.

kinship_mismatch(src, en) is True iff:
- (a) some ES concept present in src has none of its EN renderings in en; OR
- (b) some EN kinship rendering present in en maps to no concept present in src.

guard_title_en(title_src, title_en, outlet) -> tuple[str, bool] does three steps: strip ws, strip one trailing " - {outlet}", then apply the mismatch/empty fallback.
