# Phase 3 — UI Design Contract

> Visual and interaction contract for the Leaflet choropleth map island: polygon layer, filter controls, commune detail panel, geolocation, incident-pin layer, and mobile layout. Generated by gsd-ui-researcher. All tokens inherited from Phase 2 UI-SPEC.md; this document extends them for map-specific elements only.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (CSS custom properties from Phase 2 `global.css`; scoped CSS inside the React island) |
| Preset | not applicable |
| Component library | none — React island with native Leaflet 1.9.x; react-leaflet 4.x `<MapContainer>` for mount only; all choropleth via native `L.geoJSON()` inside `useEffect` |
| Icon library | Inline SVG only — port `SearchIcon` and `LocateIcon` from `ischilesafe.com/components.jsx` as island-internal constants |

## Page Layout — Map Pages

### `/map/` (EN) and `/es/mapa/` (ES)

These are dedicated full-page map views. The React island (`client:only="react"`) fills the entire viewport below the 64px header.

```
[ PageHeader — 64px, fixed or sticky ]
[ map-stage — height: calc(100vh - 64px) ]
  ├── map-canvas (Leaflet container, fills stage)
  ├── map-topbar (absolute, top: 0, left: 0, right: 0, z-index: 800)
  │   ├── SearchBox + LocateIcon button
  │   └── filters-row (year <select> + 7 crime-type chips + events toggle)
  ├── zoom-ctl (absolute, right: 16px, bottom: 120px on desktop; bottom: 180px on mobile)
  ├── Legend (absolute, bottom: 32px, left: 16px)
  ├── ResultPanel (conditional — absolute right panel on desktop, bottom sheet on mobile)
  └── Toast (conditional — absolute, bottom: 80px, centered)
```

### Desktop (> 640px)

- `map-topbar`: width 100%, `background: var(--bg)`, `padding: 8px 16px`, `box-shadow: 0 1px 0 var(--line)`
- `ResultPanel`: fixed right, `width: 380px`, `top: 64px`, `bottom: 0`, `overflow-y: auto`, `background: var(--bg)`, `border-left: 1px solid var(--line)`, `z-index: 700`; map pans left automatically via `paddingBottomRight: [410, 40]` on flyToBounds
- `Legend`: bottom-left overlay; `background: var(--bg)`, `border: 1px solid var(--line)`, `border-radius: 10px`, `padding: 12px`
- `zoom-ctl`: right-side stacked pair of 36×36px buttons; `background: var(--card)`, `border: 1px solid var(--line)`, `border-radius: 8px`; separates from Legend by ≥ 16px

### Mobile (≤ 640px)

- `map-topbar`: same structure; `filters-row` wraps to second line; minimum chip height 44px
- `ResultPanel`: bottom sheet; `position: fixed; bottom: 0; left: 0; right: 0; border-radius: 14px 14px 0 0; background: var(--bg)`; initial height 40vh with drag handle bar (40×4px, `#e2e9e8`, centered); expanded to 80vh on title tap or swipe up; close button (×) top-right 44×44px touch target
- `zoom-ctl`: hidden on mobile (pinch-to-zoom native)
- `Legend`: bottom-left; compact; `font-size: 12px` (exception — smaller than Label for overlay readability)

### `MapPlaceholderSlot` Integration (commune/region/crime-type pages)

Phase 3 mounts a lightweight centered-map view into the `[data-phase3-mount]` slot on content pages. The slot dimensions and border are NOT changed (Phase 2 contract). The island replaces only the inner content.

## Choropleth Layer — Interaction States

| State | Border color | Border weight | fillOpacity | z-order |
|-------|-------------|---------------|-------------|---------|
| Default | `#ffffff` | 1.2px | 0.55 | base |
| Hover (non-selected) | `#ffffff` | 1.8px | 0.74 | raised on hover |
| Selected (clicked) | `#0f766e` | 2.5px | 0.78 | `bringToFront()` |
| Geolocated commune | `#0f766e` | 2.5px | 0.78 | `bringToFront()` |

Tooltip: commune name only; `sticky: true`, `direction: 'top'`; 14px/700 (Label). No region name in tooltip.

Filter recolor: `layer.setStyle()` called in place — never removes or re-creates the `L.geoJSON` layer. `chroma-js` computes per-family quantile breaks client-side when a crime-type filter is active (not precomputed in payload); "todos" uses the precomputed `level` from `map-payload.json`.

Low-zoom (< 8) overlay dots: shown instead of / on top of thin polygons that are invisible at country scale. Radius: `4.5 + level * 1.1` px. Same `fillColor` from incidence scale. Click behavior: same as polygon click → opens ResultPanel.

## Filter Controls

### Year Selector

- Element: `<select>` with `.chip.select` class
- Width: auto (content); min-width 80px
- Height: 44px (touch target)
- Options: all available years from payload directory (2005–present), newest first
- Default: latest complete year (2025 per current payload)
- On change: fetch `map-payload-{year}.json` → update choropleth via `setStyle`
- Partial-year indicator: when 2026 is selected, show amber badge `Año parcial / Partial year` next to selector

### Crime-Type Chips

- 9 chips total: "Todos" (default active) + 7 crime families in this order (matching `catalog.json` + Phase 2 family order):
  1. Todos
  2. Vida y convivencia (`vida`)
  3. Propiedad (`propiedad`)
  4. Robos violentos (`robos_violentos`)
  5. Incivilidades (`incivilidades`)
  6. VIF (`vif`)
  7. Drogas (`drogas`)
  8. Armas (`armas`)
- Featured families (`vida`, `propiedad`) rendered first after "Todos"; marked with `--primary` accent dot on label (matching Phase 2 FamilyBreakdownBars pattern)
- Active chip: `background: var(--primary); color: #ffffff`
- Inactive chip: `background: var(--card); color: var(--ink); border: 1px solid var(--line)`
- Chip height: 44px; `border-radius: 999px`; `padding: 0 16px`; `font-size: 14px; font-weight: 700`
- On activate: recolor choropleth from `by_family[i]` rates using client-side quantile breaks (5 classes, natural breaks or equal-interval)

### Events (Incident Pins) Toggle

- Toggle chip: `<button class="chip ev-chip">` with `.ev-dot-mini` indicator (8×8px `#e8a05c` circle) before label
- Label: "Noticias recientes / Recent incidents"
- Active: chip background `var(--primary)`, dot visible
- Inactive: chip background `var(--card)`, dot muted
- When active and `incidents/current.json` absent: show empty-state toast (see Copywriting below)

## Commune Detail Panel

### Open behavior

- Triggered by: polygon click, low-zoom dot click, search result selection, geolocation success
- Data source: `fetch('/data/cead/comunas/{cut}.json')` — full commune data including sparkline series
- Loading state: panel renders immediately with commune name + skeleton placeholders (grey `var(--line)` bars at expected dimensions); data populates on fetch resolve
- Skeleton: 3 placeholder bars at 28px, 14px, 44px height; `background: var(--line); border-radius: 4px; animation: pulse 1.2s ease-in-out infinite`

### Panel Content (top to bottom)

1. **Panel head**: commune name (20px/700) + region name (14px/400, `var(--muted)`) + close button (×, 44×44px touch target, top-right)
2. **Level chip + CEAD attribution badge**: `LevelChip` (color dot + level label) + small "Datos CEAD" attribution pill (14px/400, `var(--muted)`)
3. **Stat card**: rate value (28px/700) — "~{rate}" (rate per 100k, formatted with `.` thousands separator) + "Tasa por 100.000 hab. ({year})" label (14px/700, `var(--muted)`)
4. **Mini-stats row**: two inline blocks — (a) Tendencia: `TrendChip` (arrow + label) and (b) Posición nacional: `#{rank} de {N}` (14px/700); separated by `var(--line)` divider
5. **Sparkline section**: heading "Evolución anual (2005–{year})" (14px/700); inline SVG bar sparkline (18px bar width, 8px gap, 44px height, `preserveAspectRatio="none"`); x-axis year labels at 2005 and {latest year} endpoints (14px/400, `var(--muted)`); active year bar fill `var(--primary)`; other bars fill level color
6. **Family breakdown**: heading "Incidencia por categoría ({year})" (14px/700); 7 horizontal bars in Phase 2 order (`vida` first); bar fill = commune level color; bar width = CSS `%` of container (rate as % of total); rate value label right-aligned (14px/400); featured families (`vida`, `propiedad`) have `--primary` accent dot before label
7. **Incidents section**: heading "Incidentes recientes" / "Recent incidents" (14px/700); 0–N incident rows (see empty state below); each row: title (16px/400), date + outlet (14px/400, `var(--muted)`), source link (14px/700, `var(--primary)`, underline)
8. **CTA button**: "Ver ficha completa" / "View full profile" — links to Phase 2 commune page `/commune/{slug}/` (EN) or `/es/comuna/{slug}/` (ES); full-width; `background: var(--primary); color: #ffffff; height: 44px; border-radius: 8px; font: 16px/700`
9. **Official source row**: small checkmark SVG (16px, `var(--primary)`) + "Fuente: CEAD" / "Source: CEAD" (14px/400, `var(--muted)`)

### Close behavior

- Close button (×): clears `selected` state; map does not re-fly; polygon border reverts to default
- Desktop: panel slides out right (CSS `transform: translateX(100%)`, 200ms ease-out); map expands back
- Mobile: bottom sheet slides down (CSS `transform: translateY(100%)`, 200ms ease-out)

## Geolocation ("Mostrar mi ubicación")

### Flow

1. User taps LocateIcon button in SearchBox trailing slot
2. Browser shows permission prompt (native)
3. **Permission granted + coordinates in Chile bounds** (`lat: -17 to -56.5`, `lng: -76.5 to -66`): identify commune via point-in-polygon against loaded GeoJSON → set as selected commune → fly to `zoom: 12` → show `.user-dot` marker → show success toast
4. **Permission granted + coordinates outside Chile**: fall back to simulate mode (Santiago [-33.44, -70.65]) → show "Ubicación aproximada: Santiago" toast
5. **Permission denied**: show error toast "No se pudo obtener tu ubicación" / "Location access denied" — no crash, no retry loop
6. **Geolocation API unavailable**: simulate mode silently

### User-dot marker

- `L.divIcon` with `.user-dot` class
- Visual: 18×18px; outer circle `border: 2px solid #0f766e`; inner dot `background: #0f766e`; white ring between them (`box-shadow: 0 0 0 2px #ffffff`)
- Tooltip: "Mi ubicación" / "My location" (direction: 'top')
- Only one marker at a time (previous removed before placing new)

### Highlighted commune state

Same visual as click-selected: `#0f766e` border 2.5px + `fillOpacity: 0.78` + `bringToFront()`. No additional visual treatment — the user-dot marker provides the location context.

## Incident Pins Layer (NEWS — MAP-04)

- `L.divIcon` with `.ev-dot` class: 14×14px, `background: #e8a05c`, `border: 1px solid #ffffff`, `border-radius: 50%`

## Empty and Error States

### Map initial load (fetching TopoJSON)

- Map container renders immediately with CARTO Positron basemap tiles
- Loading overlay: none (tiles load progressively; commune shapes appear once TopoJSON + payload fetched)
- If TopoJSON fetch fails: show centered overlay on map canvas: heading "No se pudo cargar el mapa" / "Map failed to load" (20px/700), body "Intenta recargar la página" / "Try reloading the page" (16px/400), reload button (44px height, `var(--primary)` fill)

### No commune data for selected year

- Panel stat card shows "—" instead of rate value
- Family bars show empty tracks (0% width)
- Toast: "Datos no disponibles para este año" / "Data not available for this year"

### No incidents in commune (panel incidents section)

- Section renders with heading but shows: "—" (en dash) in `var(--muted)` color, 16px/400
- No section is hidden — presence of the heading + em-dash communicates the data layer exists but has no records

### Search — no results

- Dropdown shows: "Sin resultados" / "No results" (16px/400, `var(--muted)`, centered in dropdown)

### Geolocation denied

Toast: "No se pudo obtener tu ubicación" / "Location access denied" — 3s auto-dismiss

### Toast component

- `position: fixed; bottom: 80px; left: 50%; transform: translateX(-50%)`
- `background: var(--ink); color: #ffffff; padding: 10px 20px; border-radius: 8px`
- `font: 14px/700 Nunito Sans`
- Auto-dismiss after 3000ms
- `aria-live="polite"` on container for screen readers

## Performance Constraints (MAP-06)

These are contractual, not advisory:

- TopoJSON boundary file: < 100 KB (D-01/D-02); fetched once on island mount; cached in module-level variable (not re-fetched on filter change)
- Choropleth renderer: `L.canvas()` mandatory — NOT SVG renderer. Declare `renderer: L.canvas()` in `L.geoJSON()` options.
- Style memoization: color values computed once per filter change and stored in a `Map<cut, style>` ref; `style` function reads from ref, does not recompute per-feature on each call
- No charting library: sparkline is inline SVG computed in React render; `d` path or `<rect>` elements calculated in the component
- `client:only="react"` hydration: island never SSR'd; Leaflet CSS and JS load only on map pages
- map-payload size: Phase 1 output is ~28 KB for latest year; per-year payloads are same structure; acceptable to fetch on year change
