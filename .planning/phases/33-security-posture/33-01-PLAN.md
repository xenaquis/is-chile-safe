| Job → repository token scope | `GITHUB_TOKEN`'s effective permissions for that job, gated by `permissions:` blocks |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-01 | Tampering | `actions/checkout@v7` / `setup-python@v7` / `setup-node@v7` mutable tags | mitigate | SHA-pin all 13 refs with `# vN.N.N` comments (Task 2); dependabot (Plan 33-02) keeps pins from rotting |
| T-33-02 | Elevation of Privilege | Jobs inheriting only a workflow-level or repo-default token scope | mitigate | Explicit job-level `permissions:` on all 9 jobs (Task 1 + pre-existing 3) |
| T-33-03 | Tampering | `check-sha-pins.sh` scan silently narrowed (glob typo, future refactor) and passing an undercount as green | mitigate | Hard-coded `EXPECTED_COUNT=13` assertion, non-zero exit on any count mismatch (Task 3) |
