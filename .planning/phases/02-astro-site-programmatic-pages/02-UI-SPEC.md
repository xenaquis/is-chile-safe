# Phase 2 — UI Design Contract

> Visual and interaction contract for the Astro static site + programmatic pages (346 communes, 16 regions, 7 crime-type families). Generated by gsd-ui-researcher. Source: prototype CSS tokens + CONTEXT.md D-01..D-15 + CLAUDE.md stack lock.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Tailwind CSS with scoped CSS custom properties — no shadcn; React islands reserved for Phase 3 map only) |
| Preset | not applicable |
| Component library | none (native Astro components + inline SVG for data viz) |
| Icon library | Inline SVG only — no icon library dependency; port the 3 prototype SVG icons (SearchIcon, LocateIcon, PinGlyph) as Astro partials |
| Font | Nunito Sans (Google Fonts — `wght@400;700`); fallback: "Segoe UI", system-ui, sans-serif |

Source: prototype `Chile Safety Map.html` `--font` and `<link>` declarations.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, chip internal padding |
| sm | 8px | Inline element spacing, sparkline bar gap |
| md | 16px | Default element spacing, card body padding |
| lg | 24px | Card padding, section-inner vertical rhythm |
| xl | 32px | Section vertical gap, stat-block spacing |
| 2xl | 48px | Major section breaks (hero → stats section) |
| 3xl | 64px | Header height, page-level top/bottom padding |

Exceptions:
- Header height: 64px (3xl, aligns with prototype `height: 64px`)
- Nav link touch target: 44px minimum height (accessibility — `padding: 8px 14px` + 28px font-height clears 44px)
- Map-placeholder slot minimum height: 320px on mobile, 480px on desktop (reserves visual space for Phase 3 Leaflet island without layout shift)
- Sparkline SVG height: 44px (matches prototype `height="44"`)

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Prose paragraphs, page description text |
| Label | 14px | 700 | 1.4 | Stat labels ("Tasa por 100k", rank captions), table headers, chip text, badge pills, lang-toggle buttons, methodology caveat footnotes |

Exactly 4 sizes declared: 14, 16, 20, 28px. Exactly 2 weights declared: 400 (body) and 700 (all non-body roles). Elements previously specified at 13px or 15px map to 14px (Label) and 16px (Body/Heading) respectively; weight differentiates roles within each size band.

Source: prototype inline CSS `font-size` and `font-weight` declarations, consolidated per checker contract.

## Page Layouts

### Page Type 1 — Commune Page (`/crime/{slug}/` and `/es/delito/{slug}/`)

Section order (top to bottom):

1. **PageHeader** — site wordmark + nav (Home / Map / Methodology) + lang toggle (EN/ES)
2. **CommuneHero** — h1: commune name + region name breadcrumb; level chip (1–5 color dot + label); population footnote
3. **KeyStatsRow** — 3 inline stat cards: (a) latest complete year total rate per 100k, (b) national rank (N of 346, low-pop excluded), (c) regional rank (N of region communes); each card has a label (14px/700) and value (28px/700)
4. **SparklineSection** — inline SVG bar sparkline (2005–2025 total rate per 100k); x-axis year labels at 5-year intervals; partial-year bar (2026) rendered at 50% opacity with amber caveat badge; active bar highlighted in `--primary`
5. **ComparisonCallouts** — 2 horizontal pill callouts: "X% above/below national average" and "X% above/below regional average"; sign determines color (above → level-4 amber or level-5 red tint; below → level-1/2 teal tint)
6. **CrimeFamilyBreakdown** — horizontal bar chart (pure CSS, no JS): 7 families ordered as: `vida` (featured first), `propiedad` (featured second), then `robos_violentos`, `incivilidades`, `vif`, `drogas`, `armas`; bars show latest complete year rate as % of total; featured families (`vida`, `propiedad`) have `--primary` accent dot on label; bar fill uses the commune's level color; bar width is CSS percentage of container
7. **ComparableCommune** — card block: "Similar commune: {name}, {region}" with its rate, national rank, trend chip, and a link to its commune page; uses the nearest-by-rate within region algorithm (D-05)
8. **MapPlaceholderSlot** — labeled placeholder: text "Mapa interactivo — próximamente" (ES) / "Interactive map — coming soon" (EN); dashed border `2px dashed --line`; background `--bg`; min-height 320px mobile / 480px desktop; contains a centered PinGlyph SVG icon at 40px; `data-phase3-mount="commune-map"` attribute for Phase 3 targeting
9. **ProseSummary** — the 500+ word deterministic prose block (D-01/D-02); uses body (16px/400/1.5) throughout; no bold callouts within prose except data figures which get `<strong>` at weight 700; separated from surrounding sections by 48px vertical gap
10. **MethodologyCaveat** — grey box (`--bg` background, `--line` border, `border-radius: 14px`): 2–3 sentences on subregistro, CEAD source attribution, rate-per-100k definition; font: 14px/400; includes link to `/methodology/` (EN) or `/es/metodologia/` (ES)
11. **PageFooter** — wordmark (small) + "Fuente: CEAD / Source: CEAD" attribution + locale switcher link

### Page Type 2 — Region Page (`/region/{slug}/` and `/es/region/{slug}/`)

Section order:

1. PageHeader
2. RegionHero — h1: region name; aggregate population; number of communes
3. RegionKeyStats — aggregate total rate per 100k (latest year); national position among 16 regions
4. RegionSparkline — same SVG sparkline pattern as commune, using regional aggregate series
5. CommuneRankingTable — all communes in region sorted by rate per 100k (latest complete year); columns: Commune, Rate per 100k, National Rank, Trend; low-population communes marked with a `*` footnote and excluded from rank numbering; table is server-rendered HTML `<table>` (no JS sorting in Phase 2); mobile: table scrolls horizontally
6. MapPlaceholderSlot — identical slot pattern, `data-phase3-mount="region-map"`; min-height 280px mobile / 400px desktop
7. MethodologyCaveat
8. PageFooter

### Page Type 3 — Crime-Type Page (`/crime-type/{family}/` and `/es/tipo-delito/{family}/`)

Section order:

1. PageHeader
2. CrimeTypeHero — h1: family name (localized) + definition sentence; no level chip
3. NationalRankingTable — all non-low-pop communes sorted by family rate per 100k (latest complete year); columns: Commune, Region, Rate per 100k, Trend; paginated via static HTML (show all — no JS pagination in Phase 2; at 346 rows this is ~40KB HTML, acceptable)
4. RegionBreakdownBars — horizontal bars showing each of 16 regions' aggregate rate for this family; same CSS bar pattern as family breakdown
5. MapPlaceholderSlot — `data-phase3-mount="crime-type-map"`; min-height 280px mobile / 400px desktop
6. MethodologyCaveat
7. PageFooter

## Copywriting Contract

### Voice and Forbidden Terms

Editorial sobriety is a hard constraint (D-03). The following voice rules apply to ALL generated prose, labels, headings, and callouts:

**Use:**
- "incidencia reportada" / "reported incidence"
- "tasa por 100.000 habitantes" / "rate per 100,000 inhabitants"
- "comparación relativa" / "relative comparison"
- "evolución anual" / "annual evolution"
- "datos CEAD" / "CEAD data"
- "incidencia [nivel]: baja / media-baja / media / media-alta / alta" — always qualified with "relativa"

**Never use:**
- "zona peligrosa", "dangerous zone"
- "comuna peligrosa", "dangerous commune"
- "ranking definitivo", "definitive ranking"
- "zona segura garantizada", "guaranteed safe zone"
- "la más segura", "the safest" (without qualifying "en este periodo según datos CEAD")
- Any absolute safety grade (A–F, percentage-safe, etc.)

## SEO and Schema.org

### hreflang Pattern

Every page head must include:
```html
<link rel="alternate" hreflang="en" href="https://ischilesafe.com/{path}" />
<link rel="alternate" hreflang="es" href="https://ischilesafe.com/es/{path-es}" />
<link rel="alternate" hreflang="x-default" href="https://ischilesafe.com/{path}" />
<link rel="canonical" href="https://ischilesafe.com/{self-path}" />
```
Driven by the central slug-pair map from `meta/index.json` (D-10). No per-page frontmatter hreflang.

### Meta Tags

| Tag | Value |
|-----|-------|
| `<title>` (commune EN) | "{Name} Crime Data — Chile Safety Map" |
| `<title>` (commune ES) | "Incidencia en {Nombre} — Chile Safety Map" |
| `<meta name="description">` (commune EN) | "Official CEAD crime statistics for {Name}, {Region}: reported incidence rate, national ranking, annual evolution 2005–{year}." |
| `<meta name="description">` (commune ES) | "Estadísticas CEAD de incidencia delictiva en {Nombre}, {Región}: tasa reportada, posición nacional, evolución 2005–{año}." |
| `<meta name="theme-color">` | `#0f766e` |
| `<meta name="robots">` | `index, follow` (all published pages); rollout-gated communes not built (true 404, no noindex needed) |

### Schema.org JSON-LD

Commune and region pages emit both `Dataset` and `Place`:

```json
{
  "@context": "https://schema.org",
  "@type": ["Dataset", "Place"],
  "name": "{Commune name} — Reported Crime Incidence",
  "description": "Annual reported crime incidence rates per 100,000 inhabitants for {Commune}, sourced from CEAD (Centro de Estudios y Análisis del Delito), Chile.",
  "url": "https://ischilesafe.com/crime/{slug}/",
  "spatialCoverage": {
    "@type": "Place",
    "name": "{Commune name}",
    "containedInPlace": { "@type": "AdministrativeArea", "name": "{Region name}" }
  },
  "temporalCoverage": "2005/{latest-year}",
  "measurementTechnique": "Rate per 100,000 inhabitants, official CEAD police statistics",
  "creator": { "@type": "Organization", "name": "CEAD — Centro de Estudios y Análisis del Delito" }
}
```

Crime-type pages emit `Dataset` only (no Place).

## Map Placeholder Slot Specification

The placeholder slot is the Phase 3 hydration mount point. Its contract:

```html
<div
  class="map-placeholder-slot"
  data-phase3-mount="{commune-map | region-map | crime-type-map}"
  aria-label="Interactive map — coming soon"
  role="img"
>
  <div class="map-placeholder-inner">
    <!-- PinGlyph SVG, 40px -->
    <p class="map-placeholder-label">{locale-aware placeholder text}</p>
  </div>
</div>
```

CSS contract:
- `min-height: 320px` on mobile (`max-width: 640px`)
- `min-height: 480px` on desktop
- `border: 2px dashed var(--line)`
- `border-radius: 14px` (matches `--radius`)
- `background: var(--bg)`
- `display: flex; align-items: center; justify-content: center`

Phase 3 replaces the inner content by mounting the React Leaflet island into the element matched by `[data-phase3-mount]`. The outer `div` dimensions and `data-*` attribute must not be changed in Phase 3 without updating this spec.

| Breakpoint | Width | Layout change |
|------------|-------|---------------|

```
/site/
  src/
    layouts/
      BaseLayout.astro       — head (meta, hreflang, canonical, JSON-LD, manifest link), PageHeader, PageFooter
    components/
      LevelChip.astro

      MapPlaceholderSlot.astro
      MethodologyCaveat.astro
      CommuneRankingTable.astro
    pages/
      crime/[slug].astro      — EN commune pages
      region/[slug].astro     — EN region pages
      crime-type/[family].astro — EN crime-type pages
      es/
        delito/[slug].astro   — ES commune pages
        region/[slug].astro   — ES region pages
        tipo-delito/[family].astro — ES crime-type pages
    config/
      rollout.json            — allowlist of enabled CUT codes (D-13)
      i18n.ts                 — EN/ES string map (prose labels, chip labels, page copy)
    styles/
      global.css              — CSS custom properties (tokens from this spec), reset, base typography
  public/
    manifest.json
    icon-192.png
    icon-512.png
  astro.config.mjs
```

Tailwind is **not used**. All styles are scoped CSS per-component or global CSS custom properties in `global.css`. This avoids the Tailwind build-time complexity for a site where most styling is data-driven (incidence color scale, bar widths as CSS custom properties) and keeps the HTML clean for SEO content scrapers.
