## Phase Boundary

Pre-rendered bilingual (EN/ES) static Astro site that consumes the Phase 1 `/data/cead/` JSON contract and emits SEO-valid programmatic pages for every territorial entity: 346 communes, 16 regions, and crime-type pages — each in EN (root) and ES (`/es/`). Pages are server-rendered HTML (no client-side rendering for SEO-critical content) with correct reciprocal hreflang, canonical tags, auto-generated sitemap, Schema.org structured data, and PWA meta (manifest + theme color, no service worker).

<decisions>
## Implementation Decisions

### Content generation (territorial page prose) — user-locked (interactive)
- **D-01:** Prose is generated by a **deterministic Astro template** that interpolates real Phase-1 data into varied sentence structures. Zero API cost, fully auditable, no LLM hallucination, figures match CEAD exactly. No LLM-generated prose in this phase.
- **D-02:** A **high-variation engine** mitigates thin/duplicate-content deindexing risk. Variation is combinatorial, keyed off data tiers:
  - 3 trend branches (`up`/`down`/`stable`) × 4 national-rank tiers
  - vs-national-average and vs-regional-average comparisons (both sign and magnitude phrased)
  - dominant + secondary crime-family phrasing (from `by_family` of the latest complete year)
  - a **named comparable commune** with its real data (see D-05)
  - low-population statistical-volatility caveat when `low_population: true`
  - a region-context sentence
  - Goal: each commune yields combinatorially-unique prose meeting PAGES-01 (500+ words, 5+ unique data dimensions).
- **D-03:** Editorial sobriety is mandatory (carried from PROJECT.md): use "incidencia reportada", "tasa por 100.000 habitantes", "comparación relativa", "evolución anual". Never "zona peligrosa", "comuna peligrosa", "ranking definitivo", "zona segura garantizada". (The build-time forbidden-language *gate* itself is EDIT-05 / Phase 4, but Phase 2 templates must already comply.)

### Page composition (pre-Phase-3, no live map)
- **D-04:** Each commune/region page renders **server-side static data viz**: inline **SVG sparkline** of the total rate per 100k across the full series (2005–2025), national + regional rank, crime-family **breakdown bars**, vs-national / vs-regional callouts, comparable-commune block, and a methodology/subregistro caveat. A **labeled map-placeholder slot** is reserved in the layout for Phase 3 to hydrate with the Leaflet island — no interactive map JS ships in Phase 2.
- **D-05:** **Comparable commune** = nearest commune by total rate per 100k **within the same region** (excluding `low_population` communes); fallback to nearest nationally if the region has too few qualifying communes. Always names a real commune with real data.
- **D-06:** **Crime-type pages (PAGES-03)** are built in Phase 2 as **ranking/list pages** (national + per-region tables, filtered by crime family) for the 7 families (featured categories prioritized). The map-filtered view wires in during Phase 3 via the same placeholder slot — Phase 2 does not defer these pages.
- **D-07:** **Region pages (PAGES-02)** show regional aggregates + a ranking of the region's communes by rate per 100k (low-pop communes flagged/excluded from rank per Phase-1 contract).

### URL & i18n structure
- **D-08:** `prefixDefaultLocale: false` (carried from stack) — EN at root, ES under `/es/`. Use `getRelativeLocaleUrl()` for internal links.
- **D-09:** Programmatic pages use **namespaced URL segments** to avoid collision with the hand-picked editorial slugs of Phase 4 (e.g. Santiago exists both as an editorial page and a commune):
  - Commune: EN `/crime/{slug}/` · ES `/es/delito/{slug}/`
  - Region: EN `/region/{slug}/` · ES `/es/region/{slug}/`
  - Crime-type: EN `/crime-type/{family}/` · ES `/es/tipo-delito/{family}/`
  - `{slug}` comes from `meta/index.json` (already generated in Phase 1); `{family}` is the catalog family key.
- **D-10:** **hreflang + canonical** are driven by a central **slug-pair map** generated from `meta/index.json` (and the region/family catalogs), keyed by entity id (CUT / region id / family key). The base layout injects reciprocal `hreflang` alternates (`en`, `es`, `x-default`) + a self-referential canonical on every page. No per-page frontmatter hreflang (error-prone at 692+ pages).
- **D-11:** Schema.org structured data (SEO-03): emit `Dataset` + `Place` JSON-LD on territorial pages, attributing CEAD as source.

### Deploy & batch rollout gate
- **D-12:** Phase 2 is **build-only** — produce and verify static output (`astro build` succeeds, page counts correct, hreflang reciprocal). Live Cloudflare deploy, custom domain, and GSC wiring are deferred to Phase 6. The roadmap SC "10–20 pages indexed in GSC before scaling to 346" becomes a **Phase 6 checkpoint**, not a Phase 2 blocker.
- **D-13:** **Batch gate (PAGES-04)** implemented as a config allowlist `site/src/config/rollout.json` listing enabled commune CUT codes. `getStaticPaths` and the sitemap read this list; an env flag `ROLLOUT_ALL=true` overrides to build all 346. This lets the 10–20 → 346 rollout be flipped without code changes.
- **D-14:** **Initial batch** = editorial-priority communes from PROJECT.md (~12): Santiago, Providencia, Las Condes, Maipú, Valparaíso, Viña del Mar, Concepción, La Serena, Antofagasta, Temuco, Puerto Montt, Punta Arenas. (CUT codes resolved from `meta/index.json` at plan time.)
- **D-15:** Non-batch communes are **not built** (true 404) until rollout — protects crawl budget vs shipping hundreds of `noindex` pages. Regions and crime-type pages are NOT batch-gated (small fixed counts, build all).

### Claude's Discretion
- Astro project scaffold layout under `/site/`, Tailwind-vs-scoped-CSS choice, component file organization — defer to the UI-SPEC (gsd-ui-phase runs next) and research; reuse the prototype's teal palette (`#0f766e`) and 5-level incidence scale as the visual reference.
- Exact SVG sparkline rendering approach (hand-rolled vs a tiny build-time helper), exact rank-tier thresholds for the variation engine, exact Schema.org property set.
- How crime-family breakdown bars are computed (which year, featured-category ordering).
