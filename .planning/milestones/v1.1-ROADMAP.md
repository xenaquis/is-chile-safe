## Overview

A QA/polish milestone (no new features): walk every rendered page (ES/EN) in a
real browser, hunt bugs, reduce cognitive load, and make the site pleasant to
read before go-live. Phase 7 produced the consolidated findings; Phases 8–9
applied and verified the corrections (data correctness, console cleanliness,
AdSlot CLS, UX/readability, editorial tone, accessibility, SEO meta).

The two audit-flagged partials were closed at milestone close (commit d9593a3):
F-006 (ungrammatical ES region naming) and WR-03 (keyboard-inoperable mobile
hamburger).

## Milestone Summary

**Key Decisions:**

- ROLLOUT_ALL build default committed (Phase 11 follow-on; here v1.1 ranking tables un-gated via rollout filter).
- ES region naming uses a grammatical helper (`regionNameEs`) — never the literal "Región de {name}" (closes F-006 across region pages + prose engine).
- Zero-JS hamburger remains, but the checkbox is made sr-only-but-focusable so the disclosure pattern is keyboard-operable (closes WR-03) without violating the D-09 zero-JS constraint.

**Issues Resolved:**

- Findings-ledger F-001, F-003, F-005, F-007, F-008 closed in Phases 8–9.
