<objective>
Sort news incidents newest-first (TD-03) and harden incident source-URL validation in both the frontend and the pipeline (TD-05).

Both /news/ and /es/noticias/ map over incidents in JSON insertion order with no sort. Both also guard the source link with a fragile startsWith('http://')||startsWith('https://') prefix check (news.astro:105). The map layer already has the correct pattern: IncidentPinLayer.ts safeUrl() uses new URL() + a protocol whitelist. Mirror that in both news pages AND in the pipeline store (build_incident / canonical handling) so non-http(s) URLs are rejected before persistence.

Purpose: Users see the most recent incidents first; malformed/non-http(s) URLs cannot reach the rendered DOM or the stored data.
Output: date-desc sorting + new URL()-based scheme guard on both news pages; scheme validation in store.py.
</objective>
