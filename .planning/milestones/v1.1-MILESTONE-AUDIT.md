## Cross-Phase Issues (confirmed in source + build)

1. **WR-03 — mobile hamburger keyboard inoperable** `[A11Y-01, BUGFIX-05]` (warning)
   `PageHeader.astro:46` checkbox is `tabindex="-1"` + `aria-hidden`; `:47` `<label>` has no `tabindex`. No keyboard path to open the mobile nav. Phase 8's WR-02 fix (remove hidden checkbox from tab order) created this when paired with the deferred WR-03. Fix candidate: `tabindex="0"` + `role="button"` + key handler on the label, or a minimal zero-JS reconsideration.

2. **F-006 — ES region display name ungrammatical** `[READ-02]` (warning)
   `es/region/[slug].astro:157` and `i18n.ts:240` template `Región de {name}`, producing "Región de Metropolitana" / would also misfire for any name not taking "de". 5 occurrences in `dist/es/region/metropolitana/index.html`. Fix: special-case "Metropolitana" → "Región Metropolitana" (and audit the other 15 regions for the "de/del" rule). *Adjacent observation:* `ResultPanel.tsx` region-name map (lines 82–98) is missing key `'13'` (Metropolitana) — jumps 12→14; worth confirming RM panels resolve their region label.
