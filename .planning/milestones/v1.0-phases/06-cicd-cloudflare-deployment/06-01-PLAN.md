<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner -> external endpoints (RSS feeds, CEAD, DeepSeek API) | Outbound; untrusted responses parsed by scrapers (already validated/atomic in Phase 1/5) |
| GitHub Actions runner -> repo (git push via GITHUB_TOKEN) | Write boundary; only data/ is staged |
| GitHub Actions runner -> Cloudflare Pages (Deploy Hook curl) | Outbound POST with a secret URL |
| Repo Actions secrets -> workflow env | Secrets cross into job env; must never be logged |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | DEEPSEEK_API_KEY in news-pipeline.yml | mitigate | Referenced only as ${{ secrets.DEEPSEEK_API_KEY }} in a step env: block; never echoed. GitHub masks secret values in logs by default. |
| T-06-02 | Information Disclosure | CF_DEPLOY_HOOK_URL in both workflows | mitigate | Mapped to env CF_HOOK; used only in curl -X POST "$CF_HOOK"; never printed. Treated as a secret URL (a deploy capability). |
| T-06-03 | Elevation of Privilege | GITHUB_TOKEN scope | mitigate | permissions: contents: write ONLY (least-privilege per Pitfall 3); no other scopes granted. |
| T-06-04 | Tampering | Pinned action versions (supply chain) | mitigate | actions/checkout@v4, actions/setup-python@v5 pinned to major versions; no @main / unpinned refs. |
| T-06-05 | Denial of Service | Rebuild loop / build-quota exhaustion (INFRA-02) | mitigate | Deploy Hook curl gated on changed==true; git add data/ excludes docs; CF auto-build disabled in dashboard (DEPLOYMENT.md, plan 06-03). |
| T-06-SC | Tampering | npm/pip installs | accept | No NEW packages introduced this phase; pipeline/requirements.txt already vetted (Phases 1 & 5). RESEARCH Package Legitimacy Audit: no [SLOP]/[SUS]. |
</threat_model>
