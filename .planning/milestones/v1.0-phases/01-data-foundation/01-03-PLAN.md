<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline → CEAD government server | Outbound requests to a government endpoint with no SLA and no documented rate limit |
| CEAD response → parser | Untrusted HTML (encoding, locale, structure) crosses into our data layer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Denial of Service (to CEAD) | HTTP client request volume | mitigate | 2.5 s inter-batch delay (D-03); region-batched requests (~16 batches) not per-commune; single live call for fixture capture |
| T-03-02 | Tampering | Malformed/corrupted CEAD HTML | mitigate | parse_cead_float maps unparseable/missing to None; structural validation deferred to schema gate (Plan 01) before any write |
| T-03-03 | Information Disclosure | latin-1 mis-decode corrupting commune names | mitigate | Mandatory .content.decode('latin-1') (Pitfall 3); tested against accented fixture |
| T-03-04 | Repudiation | Unverified endpoint behavior drift | mitigate | Blocking human checkpoint confirms live 200 + real rows before Plan 04 depends on params |
</threat_model>
