<objective>
Submit the v2.0 sitemap to Google Search Console immediately after the first v2.0 deploy and confirm representative pages are indexable via URL Inspection (GL-04).

Purpose: A correct sitemap submitted right after launch is how Google discovers the ~792+ v2.0 pages quickly — the SEO core value of the project depends on indexation.
Output: Sitemap submitted in GSC; URL Inspection verified on representative commune + A-vs-B pages. (No code changes expected — this is a launch-ops verification plan.)
</objective>
