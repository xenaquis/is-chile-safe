## Decisions Made

- PNG generation via hand-encoded PNG binary (signature + IHDR + IDAT IEND + CRC32 per spec) — one solid-color scanline per row with filter byte 0, deflated via `deflateSync`. Deterministic, byte-reproducible.
- `buildItemList` `urlMode` option added to handle `/rankings/` case where items are crime-type index pages, not `/commune/` slugs.
- `extractAllJsonLd` uses a `while((m=re.exec(html))!==null)` loop (not `.match`) so all blocks in pages carrying 2-3 JSON-LD scripts are extracted.
- OG assertions in `seo.mjs` guarded behind presence of `og:title` — validator exits 0 on pre-Plan-02 build; PNG existence check always-on as an unconditional gate.
