### Is the NO-GO genuinely actionable for Phase 27/28? — judged strictly

**Yes.** This is not a bare "it didn't work". Concretely:

1. **Named, counted failure modes with mechanism**, not vibes: aggregate/roundup-vs-component merging (**10 of 11 FPs**, with the mechanism stated — the model treats shared location+date+operative-type as sufficient); procedural-stage merging (detention → formalization → conviction conflated); conflicting-sentence merging (**1 of 11**, Tongoy, 19y vs 8.5y merged despite the sentence delta being the strongest discriminator).
2. **A falsified design assumption, with data**: `confidence` was `"high"` on 94/94 verdicts, so the `confidence == "high"` half of F-03's mergeable rule rejected **zero** pairs. The report draws the correct conclusion — a future attempt cannot use model self-reported confidence as a precision lever and must add explicit fact-level schema checks (procedural stage, sentence/charge specifics, aggregate-vs-single-suspect framing).
3. **Every FP is individually auditable** — 11 `pair_id`s listed, each with both titles and the model's own rationale, and each independently confirmed a genuine model error (F-15: 22/22 unanimous `different` from two blind reviewers, checking the *opposite* label direction from F-06). This closes the one way a NO-GO could have been fabricated.
4. **An explicit downstream instruction**: "Phase 28's NEWSUI-05 degrades to faceting-only." Phase 27 was already independent by roadmap design.
5. **A cheap re-entry path that actually exists**: the golden set and both offline regressions are committed, so a future attempt re-runs a fill + the gate test rather than rebuilding ground truth.
6. **A non-obvious honesty note** that prevents a future misreading: even a GO would have populated nothing, because `store.py:merge_and_write` writes raw dicts — a producer step is a Phase 28 prerequisite. It also honestly scopes the verdict to same-day `(cut,date)` buckets and flags the ±1-day window as untested, and admits the real cost bound is bucketing (13.1% reduction), not the lexical pre-filter.

Phase 27/28 are not left guessing. The one structural risk to this deliverable is W-2 (a script re-run deletes items 1, 2, 4, and 5 from the report).
