## 4. The swarm (enjambre) — review design

Run as a **Workflow** (multi-agent orchestration; user explicitly opted in with "enjambre sonnet validadores opus"). Pattern: parallel Sonnet validators by dimension → Opus synthesis → remediation backlog + methodology/sources spec on disk. Each validator writes a structured finding set; Opus dedupes, prioritizes (blocker/should/defer), and emits the v1.3 plan.

**Validator dimensions (one Sonnet agent each, parallel):**
1. **Tech-debt sweep** — re-verify every item in §2 against the live repo (still applies? already fixed?), plus a fresh grep for TODO/FIXME/HACK/stub/`nyquist_compliant: false`/skipped tests. Output: confirmed debt list w/ file:line + fix sketch.
2. **Methodology completeness** — read `methodology.astro` + `es/metodologia.astro` + every page that displays a number (commune, ranking, crime-ranking, region, home). For each displayed figure/rule, assert: explained? sourced+linked? caveated? EN/ES parity? Output: gap table per figure.
3. **Source coverage & expansion** — enumerate every data file the site loads (`data/cead/**`, `data/snapshots/**`, `data/incidents/**`, `featured_rates`, `by_family`) and map each to a `data/SOURCES.md` entry; flag unsourced figures; propose the new source classes from §3 with exact official URLs + measure semantics. Output: expanded SOURCES.md spec.
4. **Data correctness re-verify** — re-run `pipeline/scripts/verify_data_quality.py`; re-check the 4 anomalies, partial-year flags, drug scope, per-100k semantics; confirm no displayed-metric drift. Output: pass/fail evidence.
5. **SEO / integration / spine** — dead links, hreflang reciprocity, sitemap coverage (incl. `/news/`), nav+footer spine completeness, COMU-03 orphan, localized-slug correctness. Output: wiring gaps.
6. **Code quality & security** — pipeline (resolver, classifier, ab_score, snapshot scripts) + frontend (news pages, IncidentsList, IncidentPinLayer): bugs, XSS (escHtml/scheme guards), error handling, two-sources-of-truth. Output: severity-classified findings.
7. **Bilingual parity** — EN/ES parity across ALL pages (not just methodology): missing translations, hardcoded strings, `getRelativeLocaleUrl` misuse on localized slugs.

**Synthesis (Opus):** merge all validator outputs → dedupe → prioritize → write:
- `.planning/v1.3-REVIEW-FINDINGS.md` (full findings, by dimension + severity)
- `.planning/v1.3-METHODOLOGY-SPEC.md` (the well-specified methodology + expanded-sources contract — the build target)
- A proposed v1.3 ROADMAP phase list (e.g., P19 tech-debt sweep, P20 methodology+sources hardening) ready for `/gsd:new-milestone`.

**Scale:** ~7 Sonnet validators (read-only, parallel) + 1 Opus synthesizer. Adversarially verify any "confirmed bug" before it enters the remediation backlog (1 skeptic per high-severity finding). No live API spend except the DQ harness re-run (offline) + optional BrowserOS visual (inline, main context).
