<objective>
Create `.github/workflows/deploy-on-code.yml` so that pushing SITE CODE to `master`
automatically redeploys Cloudflare Pages production via the Deploy Hook.

Purpose: Cloudflare Pages automatic production builds are DISABLED (DEPLOYMENT.md §4) to
prevent a rebuild loop from the every-6h data commits. Side effect: code pushes to `master`
never redeploy production — the only existing trigger is the Deploy Hook, which the cron
workflows curl ONLY when `data/` changes. Result: v1.2 code shipped but production serves a
stale build. This workflow closes that gap for code pushes WITHOUT reopening the loop.

Output: a single new workflow file. No other files change.
</objective>
