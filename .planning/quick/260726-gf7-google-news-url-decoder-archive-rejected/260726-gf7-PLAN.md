## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RSS/gnews URL → full-text fetcher | Untrusted URL (from RSS feed or decoded from Google News) crosses into an outbound HTTP GET |
| Article server → trafilatura/text store | Untrusted response body (size, content-type) crosses into parsing + R2 upload |
| news.google.com batchexecute → decoder | Untrusted JSON-ish response parsed for a target URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-gf7-01 | Information Disclosure (SSRF) | fetch_article on decoded URL | mitigate | is_safe_url rejects non-http(s), credentialed userinfo, and private/loopback/link-local IP literals — applied to BOTH original and decoded URL, no DNS resolution |
| T-gf7-02 | Denial of Service | fetch_article response body | mitigate | Streamed 5 MB hard ceiling via iter_content (ignore Content-Length); abort over-limit as failure |
| T-gf7-03 | Tampering | Content-Type of fetched resource | mitigate | Only text/html or text/plain processed; PDFs/binaries skipped as failure |
| T-gf7-04 | Spoofing | batchexecute host | mitigate | POST host hardcoded to news.google.com/_/DotsSplashUi/data/batchexecute — never derived from input URL |
| T-gf7-05 | Information Disclosure | decoder + fetcher logging | mitigate | logger.debug only in decoder; never log full response bodies or secrets (existing pattern preserved) |
| T-gf7-06 | Tampering | live url-ledger (1,264 rows) backward compat | mitigate | Legacy rows without kind default to "incident" on merge; append-only "fetched" immutability preserved; do not corrupt existing rows |
| T-gf7-SC | Tampering | npm/pip installs | accept | No new dependencies — decoder implemented inline (no googlenewsdecoder package); requirements.txt unchanged |
