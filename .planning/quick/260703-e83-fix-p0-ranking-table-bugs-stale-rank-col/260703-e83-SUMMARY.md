# Quick Task 260703-e83: Fix P0 Ranking Table Bugs (Stale Rank Column)

## What Was Fixed

**BUG 1 — Stale rank column on year change:** RankingTableEnhancer now accepts optional `data-rank-col` (comma-separated td indices) and `data-rank-note` (localized tooltip) table-level attributes. On init, it stores the server-rendered rank text in `data-orig-rank` on each rank cell. On year change, rank cells blank to "—"; on return to the default year, they restore from `data-orig-rank`. The `data-year-target` attribute on any element causes it to track the selected year. Both are backward-compatible (absent = no-op).

Wired to:
- crime-ranking EN/ES: `data-rank-col="0"`, `<span data-year-target>` in `<h2>`
- safest-cities EN/ES: `data-rank-col="0,4"` (position + national rank), `<span data-year-target>` in `<caption>`
- CommuneRankingTable: `data-rank-col="2"` (national rank column)

**BUG 2 — Internal 404 comparator links:** Added `loadEnabledPairSlugs()` to data.ts — reads `data/comparator-pairs.json`, filters `enabled === true`, returns a memoized `Set<string>` of `${cutA}-vs-${cutB}` slugs. Both commune/[slug].astro (EN) and es/comuna/[slug].astro (ES) now filter `comparatorPairs` to enabled slugs before rendering `<ComparatorPairsLinks>`, which is itself rendered conditionally (`comparatorPairs.length > 0`). Region-10 communes still emit valid pair links; region-13 (e.g. Providencia) emits no comparator spoke. spine.mjs assertion M rewritten to fail if ANY commune page links a non-enabled pair (previously it required all pages to have a link — the root cause of the 404s).

**BUG 3 — Similar-communes table static (non-sortable):** `RankingRow` interface extended with `ratesByYear: Record<number, number>`. `nearestComparables()` now builds `ratesByYear` from complete series entries (`!s.partial`, using `rate_per_100k`), which matches the displayed `rate` (latestCompleteYearRate). CommuneRankingTable rows now carry `data-rates` JSON, so RankingTableEnhancer's `hasRatesData` guard passes and the year select + sort controls appear.
